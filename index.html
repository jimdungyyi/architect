완벽한 방어를 위한 투트랙(Two-Track) 아키텍처

큰 모델의 느림과 비용을 없애고, 실무형 판단의 깊이는 극대화했습니다.

⚡️

1. 온디바이스 경량모델

클라우드 호출 없이 앱 내부에서 즉시 구동되는 바이너리 모델

  • 65,536차원 해시 기반 특징 공간으로 메모리 효율 극대화
  • 구조화 필드와 도메인 키워드 조합으로 위험 신호 즉시 감지
  • Ed25519 서명 및 SHA-256 적용으로 무결성 검증 완비
🧠

2. 문서 취약점 추론엔진

단순 점수 산출을 넘어선 '사건 맥락' 해석기

  • 어디가 취약한지, 어떻게 반박당할지 실무형 진단 제공
  • 관찰과 추정 혼합 파악, 증빙 연결 등 기록 품질 진단 특화
  • 단순 분류기가 아닌 문서 보강 조치 제안 로직 탑재

무거운 LLM 대신, 빠르고 정확한 도메인 최적화.

비용 절감, 압도적 속도, 완벽한 프라이버시를 동시에 달성하는 루지코지 코어 모듈

⚠️

취약점 분석 및 보강 조치 제안

"이 기록은 시간 정보가 불완전합니다", "관찰과 추정이 혼합되어 반박당할 위험이 있습니다." AI가 단순한 위험도 랭킹을 넘어 어디가 취약한지, 지금 무엇을 보강해야 하는지 실무적인 설명 이유를 즉시 구조화하여 제시합니다.

🔒

100% 온디바이스 프라이버시

민감한 교육/학생 데이터를 외부 서버로 보내지 마세요. 로컬 환경에서 독립적으로 구동되어 외부 유출을 원천 차단하고 클라우드 API 호출 비용을 0원으로 만듭니다.

⚡️

초경량 고속 위험 분류망

3클래스 선형 모델 구조와 주체, 장소, 민감도 필드를 빠르게 벡터화하여 사건의 위험 신호를 즉시 분류하는 해시 기반의 고효율 아키텍처입니다.

🛡️

암호학적 기록 무결성 검증

기록은 분석만큼이나 보존과 증명이 중요합니다. Ed25519 서명, SHA-256 해시, Payload 검증 체계를 통합하여 분쟁 시 법적 방어력을 갖춘 신뢰성 있는 문서 데이터를 보장합니다.
